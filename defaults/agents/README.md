# Default Agents

Neo OrchestraX ships with default role-oriented agents. These are configuration artifacts consumed by the agent resolver rather than hard-coded orchestration logic.

Current defaults:

- `java-dev`
- `android-dev`
- `web-angular-dev`
- `web-vanilla-dev`

Each agent declares its role, capabilities, applicability, and instruction dependencies. Skills are intentionally deferred to V0.12.
