# V0.17.1 — Automatic Project Board Dependency Installation

V0.17.1 completes Project Manager provisioning of Neo Project Board.

When the Project Manager pack is installed at project scope, OrchestraX now:

1. Ensures the Project Hub exists.
2. Installs/registers the Project Manager pack.
3. Clones Neo Project Board into `<project>-docs/neo-project-board` when absent.
4. Validates the Board manifest and compatibility contract.
5. Runs `npm install` inside `<project>-docs/neo-project-board`.

The same dependency installation occurs when `neo board install <project>` is used. An existing valid Board checkout is synchronized with `npm install` rather than recloned or overwritten.

The React application remains a separate Git repository and is never copied into the Neo OrchestraX repository.
