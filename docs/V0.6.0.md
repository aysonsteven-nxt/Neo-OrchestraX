# V0.6.0 — Context Resolver

V0.6 introduces the Context Resolver.

The purpose is to prevent OrchestraX from dumping all project knowledge into every task. It selects a focused context from available project intelligence.

## Inputs

Initial inputs:

- Project Profile from the analyzer
- Syntra entries
- Optional task/query text

## Resolution

```text
@context for MoneyMap
        |
        v
Project Resolver
        |
        v
Context Resolver
   +----+----+
   |         |
Profile    Syntra
   |         |
   +----+----+
        |
 relevance
        |
        v
Focused Context
```

## Relevance

Syntra entries are matched against the requested query.

Governance status affects relevance:

- confirmed: positive weight
- review: smaller positive weight
- draft: neutral
- rejected: negative/excluded
- superseded: negative/excluded

Project Profile signals are also included as contextual evidence.

## CLI

```text
neo context MoneyMap
neo context MoneyMap authentication
```

This is diagnostic access to the same resolver. The intended primary interface remains:

```text
@context
@context for MoneyMap
```

There is still no `@syntra` command.
