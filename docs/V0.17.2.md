# Neo OrchestraX v0.17.2

## Windows npm process fix

v0.17.2 fixes Neo Project Board dependency installation and launch on Windows.

On Windows, npm is invoked through `ComSpec`/`cmd.exe` instead of spawning `npm.cmd` directly, avoiding `spawnSync npm.cmd EINVAL`.

The Project Manager installation flow remains:

1. Ensure the Project Hub exists.
2. Clone Neo Project Board into `<project>-docs/neo-project-board` when absent.
3. Validate the Board manifest and compatibility contract.
4. Run `npm install` automatically inside the cloned Board.
