# V0.8.0 — Handoff / Resume

## Purpose
Provide cross-session and cross-provider continuity without turning Syntra into a session log.

## Handoff
A handoff records:
- project and optional task
- objective and task status
- completed/in-progress work
- active files
- recent changes
- decisions
- constraints
- open questions
- known problems
- next action
- optional provider, agent, and session metadata

Stored at:
```text
<project>/.orchestrax/handoff/handoffs.json
```

## Resume
Resume retrieves the latest handoff for the selected project, or a specific handoff through the diagnostic CLI.

## AI-facing commands
```text
@handoff
@handoff for MoneyMap
@resume
@resume for MoneyMap
```

The user interacts with Neo OrchestraX. Syntra remains an internal subsystem.

## Diagnostic CLI
```text
neo handoff create MoneyMap
neo handoff create MoneyMap <task-id>
neo handoff list MoneyMap
neo handoff show MoneyMap <handoff-id>
neo handoff latest MoneyMap
neo resume MoneyMap
neo resume MoneyMap <handoff-id>
```

## Boundary
Handoff does not claim to inspect private Copilot, Gemini, Claude, Cursor, or other provider conversations. Provider/session fields are explicit metadata only.
