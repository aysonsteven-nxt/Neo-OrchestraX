# V0.7.0 — Task / Workflow Integration

V0.7 introduces structured tasks and connects task state to the Context Resolver.

A task tracks:
- objective
- status
- relevant packs
- context query
- completed work
- in-progress work
- open questions
- known problems
- next action

Statuses: `planned`, `in-progress`, `blocked`, `completed`, `cancelled`.

Project-local storage:
```text
<project>/.orchestrax/tasks/tasks.json
```

Task context combines the task objective/questions with Project Profile and Syntra through the Context Resolver.

Diagnostic CLI:
```text
neo task start MoneyMap "Transaction history" "Implement transaction history"
neo task list MoneyMap
neo task show MoneyMap <task-id>
neo task status MoneyMap <task-id> in-progress
neo task context MoneyMap <task-id>
```

The AI-facing command remains `@task`; Syntra remains internal.
