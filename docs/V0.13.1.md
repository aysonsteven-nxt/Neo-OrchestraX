# V0.13.1 — Command UX + Copilot Slash Actions

V0.13.1 changes the canonical OrchestraX AI-facing syntax from `@command` to `/command`. The parser still accepts `@command` as a backward-compatible alias.

## Slash commands

```text
/package-selector for MoneyMap
/package-install android-kotlin-dev for MoneyMap
/context for MoneyMap
/handoff for MoneyMap
/resume for MoneyMap
``

The command router remains the canonical execution path.

## Copilot integration

Current GitHub Copilot Agent Host exposes Agent Skills as slash commands. OrchestraX therefore generates user-level Copilot skills rather than introducing a VS Code extension.

Install/sync the projection with:

```text
neo provider sync-user copilot
```

Generated files are written to the Copilot user skill directory (`~/.copilot/skills`) and are marked as OrchestraX-managed. Unmanaged files are skipped rather than overwritten.

The canonical definitions remain inside `neo-orchestrax`. The Copilot files are provider projections only.

## CLI

```text
neo provider sync-user copilot
```

## Package actions

The routed AI actions `/package-selector` and `/package-install` now execute their corresponding OrchestraX pack recommendation/install operations rather than only acknowledging the route.
