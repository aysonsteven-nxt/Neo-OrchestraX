# V0.4.0 — Pack Selector

V0.4 introduces deterministic project analysis and Pack recommendation.

## Project analysis

The analyzer detects local evidence such as:

- Android
- Kotlin
- Java
- TypeScript
- Gradle
- Maven
- Spring Boot
- Jetpack Compose
- Room
- Hilt
- Angular
- test structure
- common architecture/layer signals

## Pack selection

Pack recommendations are based on declared pack capabilities matched against detected project signals.

Scores represent **technical relevance/match**, not quality rankings.

Example:

```text
Project Analysis: MoneyMap

✓ Android
✓ Kotlin
✓ Jetpack Compose
✓ Gradle
✓ Room
✓ Hilt
```

```text
Pack Recommendations: MoneyMap

android-kotlin-dev  100%
solutions-architect 80%
project-manager      70%
```

## CLI

```text
neo analyze MoneyMap
neo pack recommend MoneyMap
```

## AI command

```text
@package-selector
@package-selector for MoneyMap
```

The command layer resolves the project; V0.4 adds the analyzer and selector implementation behind it.
