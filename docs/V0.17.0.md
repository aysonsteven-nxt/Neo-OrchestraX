# V0.17.0 — Neo Project Board Provisioning

V0.17.0 integrates the separate **Neo Project Board** application with the Project Hub without making the React application part of the Neo OrchestraX repository.

## Locked architecture

```text
Neo OrchestraX
    │
    │ neo CLI
    ▼
<project>-docs/
├── hub.json
├── packs/
├── board/
├── discussions/
└── neo-project-board/       # cloned external repository
    ├── neo-project-board.json
    ├── package.json
    └── React/Vite application
```

Neo Project Board remains its own repository:

`https://github.com/aysonsteven-nxt/Neo-Project-Board`

The Project Hub filesystem remains the source of truth. The Board is a local UI over that data.

## Project Manager integration

When `project-manager` is installed at project scope, OrchestraX provisions Neo Project Board into the project's Project Hub.

The Board repository is cloned only if it is not already present. Existing Board installations are never overwritten by `neo pack install`.

## Board CLI

```text
neo board install <project>
neo board status <project>
neo board update <project>
neo board launch <project>
```

- `install` clones the Board repository when absent and validates its manifest.
- `status` reports installation path, version, and compatibility.
- `update` performs a fast-forward-only Git pull.
- `launch` runs the Board's local Vite development server.

## Compatibility

The Board must declare:

```json
{
  "schema": "neo-orchestrax/project-board-app@1",
  "app": "neo-project-board",
  "contract": "neo-orchestrax/project-board@1"
}
```

V0.17.0 supports Board version `0.4.0` and newer versions using the same contract.

## Boundaries

Neo OrchestraX contains only the provisioning/integration logic. It does not contain React, Vite, or the Board application's source code.
