# V0.15.1

- Added the npm `bin` declaration for the `neo` CLI.
- Added a Node CLI shebang to the entry point.
- Added `neo --version`, `neo -v`, and `neo version`.
- CLI help and workspace status now read the version from `package.json` instead of hard-coding it.

This is a focused patch over V0.15.0; the V0.15 workspace, project, pack, context, Syntra, task, handoff, provider, instruction, agent, skill, and AI-command functionality is unchanged.
