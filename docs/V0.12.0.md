# V0.12.0 — Skills

V0.12 introduces reusable Skills mapped to Agents.

## Skills

Each skill contains `skill.json` and `skill.md`, with metadata for version, category, capabilities, project applicability, mapped agents, optional instruction dependencies, priority and overrideability.

## Layers

Skills resolve from:

1. OrchestraX defaults
2. User (`~/.orchestrax/skills`)
3. Workspace (`.orchestrax/skills`)
4. Project (`.orchestrax/skills`)

## Agent mapping

Agents now declare skill dependencies with `id`, `version`, and `required`. V0.12 ships default mappings for Java, Android, Angular and vanilla web agents.

## Commands

```text
neo skill list <project> [agent-id]
neo skill show <project> <skill-id>
neo skill effective <project> [agent-id]
neo skill validate <path>
```

AI-facing:

```text
@skills
@skills for MoneyMap
@skill android-development for MoneyMap
```

## Provider context

Provider adapters now include each agent's resolved skill dependencies so generated provider artifacts describe both the agent role and its capabilities.
