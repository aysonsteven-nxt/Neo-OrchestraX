# V0.18.0 — AI/Agent Project Collaboration & Context

V0.18.0 extends the Project Hub so AI/Agents can understand and contribute to the same project-management data used by Neo Project Board.

## Source of truth

No new database or parallel AI memory store is introduced. The Project Hub filesystem remains canonical:

```text
<project>-docs/
├── hub.json
├── board/
│   ├── board.json
│   ├── epics/
│   ├── stories/
│   └── subtasks/
├── discussions/
└── neo-project-board/
```

## Agent-readable context

`neo project context <project>` emits a structured `neo-orchestrax/project-context@1` document containing the project Hub, board configuration, epics, stories, subtasks, comments, applicable agents, effective instructions, and effective skills.

`neo story context <project> <story-id>` emits focused context for one User Story, including its Epic, subtasks, discussion comments, and applicable agent capabilities.

These outputs are designed to be consumed by an AI/Agent without requiring the React Board to be present.

## Persistent collaboration

`neo story comment <project> <story-id> <author> "<comment>"` appends a discussion comment directly to the User Story JSON.

Agent contributions therefore become normal project information and are visible to Neo Project Board.

## Boundaries

- No AI provider is mandatory.
- No cloud service is required.
- No second collaboration database is introduced.
- Neo Project Board remains a separate repository.
- AI/Agent collaboration uses the existing Project Hub JSON/filesystem model.
