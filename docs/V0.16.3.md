# Neo OrchestraX V0.16.3

## Active VS Code Workspace Registration

V0.16.3 fixes Project Hub registration for VS Code multi-root workspaces when the active workspace file cannot be discovered from the current project path.

### Behavior

When a hub pack is installed:

```text
neo pack install project-manager <project>
```

OrchestraX creates the Project Hub and registers it with the **currently active VS Code window** using the VS Code CLI:

```text
code --add <project>-docs
```

This works for saved multi-root workspaces and untitled workspaces. A known `.code-workspace` file remains a fallback when the VS Code CLI is unavailable.

### Why

A CLI cannot safely assume that the first `.code-workspace` file found in a parent directory is the active VS Code workspace. Multiple workspace files may reference the same project. VS Code's `--add` operation provides the authoritative active-window boundary.

### Scope

- No new AI Commands.
- Native CLI remains the primary interface.
- `neo command "/..."` remains compatibility-only.
- React/Vite Project Board remains planned for V0.17.
