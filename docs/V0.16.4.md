# Neo OrchestraX V0.16.4

## Workspace Resolution and Project Hub Registration

- Resolve saved VS Code workspaces by project membership instead of selecting an unrelated `.code-workspace` from a parent directory.
- Preserve support for projects located outside the physical workspace-file directory.
- Use VS Code `--reuse-window --add` for Project Hub registration so the generated `<project>-docs` folder is added to the active workspace, including untitled workspaces.
- Do not silently associate a project with an unrelated workspace file.
- Project Hub remains outside the project repository.
