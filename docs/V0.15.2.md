# V0.15.2

## AI Command Compatibility

- Promoted the CLI bridge for canonical OrchestraX AI commands from a diagnostic-only description to a documented **AI Command Compatibility** interface.
- `neo command "<AI command>"` executes the same canonical `/...` command language used by the AI Command Engine and provider integrations.
- Added representative examples for package selection/install, context, task, handoff/resume, instructions, agents, skills, and provider sync.
- Clarified that native `neo ...` commands remain the direct CLI interface, while `neo command` is the compatibility interface for the canonical AI command syntax.
- No new command engine or provider-specific command implementation was introduced; the existing shared AI Command Engine remains the source of execution behavior.
