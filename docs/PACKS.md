# Pack Model

A Pack is a bundle of reusable AI development capabilities.

Current canonical metadata:

```json
{
  "name": "android-kotlin-dev",
  "version": "0.1.0",
  "description": "...",
  "capabilities": [],
  "agents": [],
  "skills": []
}
```

Future metadata can add:

- instructions
- prompts
- templates
- dependencies
- compatibility
- provider mappings
- lifecycle metadata

The canonical pack definition belongs to OrchestraX. Provider-specific artifacts are generated later.
