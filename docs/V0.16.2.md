# Neo OrchestraX V0.16.2

## Workspace Project Hub Registration

V0.16.2 extends the V0.16 Project Hub foundation so a generated Project Hub is automatically registered in the active VS Code multi-root workspace.

### Behavior

When a project-scoped hub pack is installed:

```text
neo pack install project-manager <project>
```

Or through the legacy AI Command compatibility bridge:

```text
neo command "/package-install project-manager for <project>"
```

OrchestraX:

1. Resolves the active workspace and project.
2. Creates `<project>-docs` at the resolved Project Hub location.
3. Registers that folder in the active `.code-workspace` file when one is available.
4. Avoids duplicate workspace-folder registrations.
5. Preserves the existing project and workspace relationship.

The Project Hub remains outside the project repository.

### Example

```text
.sample-workspace
├── gov-requirements-checker
└── gov-requirements-checker-docs
```

The second workspace folder may physically resolve to a location such as:

```text
C:\Users\ayson\Documents\gov-requirements-checker-docs
```

The workspace file is the registration boundary; projects themselves may live elsewhere.

### Scope

- No new AI Commands.
- Native CLI remains the primary interface.
- `neo command "/..."` remains compatibility-only.
- React/Vite Project Board remains planned for V0.17.
