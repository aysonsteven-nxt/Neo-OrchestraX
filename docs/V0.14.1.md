# V0.14.1 — Workspace / OrchestraX Root Discovery Fix

This is a V0.14.0 bug-fix release.

## Fixed

- AI Command diagnostic bridge now works when invoked from inside the Neo OrchestraX distribution directory.
- OrchestraX root discovery uses the canonical package identity (`name: neo-orchestrax`) rather than assuming a folder named exactly `neo-orchestrax`.
- Versioned release directories such as `neo-orchestrax-v0.14.1` are supported.
- Provider synchronization uses the discovered OrchestraX root rather than assuming a fixed sibling directory name.

## AI Command example

```text
node dist/index.js command "/package-selector for gov-requirements-checker"
```

This can now be executed from the Neo OrchestraX distribution directory when it is located alongside the target project(s) in the workspace.
