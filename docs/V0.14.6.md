# V0.14.6 — Provider Command Projection

V0.14.6 connects the provider-neutral AI Command model to provider-specific command projection without changing the canonical OrchestraX command definitions.

## Canonical source

Commands remain in `commands/*.command.md` and are provider-neutral.

## Copilot projection

The Copilot adapter generates an Agent Plugins 1.0 package under `providers/copilot/`. Copilot-specific slash commands are emitted under `com.github.copilot/commands/`. VS Code/Copilot can consume the plugin without introducing Copilot-specific files into managed projects.

The adapter is the provider-specific layer; the core command registry/parser/router remains provider-neutral.

## Build

`npm run build` compiles the core and regenerates the Copilot plugin projection from the canonical command definitions.

## Important

The generated plugin is a provider artifact. It is not the canonical source of the OrchestraX commands. Installing/activating the plugin in a provider remains a provider-specific operation.
