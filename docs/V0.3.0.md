# V0.3.0 — Pack System

V0.3 introduces the canonical Pack foundation.

## Pack metadata

Each pack has `pack.json` containing:

- name
- version
- description
- capabilities
- agents
- skills

## Built-in packs

- project-manager
- solutions-architect
- android-kotlin-dev
- java-dev

## Pack lifecycle

Implemented at the CLI foundation level:

- list
- validate
- install
- installed
- remove

Installed packs are project-local:

```text
<project>/
└── .orchestrax/
    └── packs/
        └── <pack>/
```

## AI command catalog

V0.3 recognizes:

```text
@package-selector
@package-install <package>
@package-list
@package-installed
@package-remove <package>
@package-validate
@context
@task
@handoff
@resume
```

The package commands are routed through OrchestraX. Full AI-driven package selection is a later increment.
