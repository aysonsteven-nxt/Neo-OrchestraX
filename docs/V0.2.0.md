# V0.2.0

## Goal

Introduce the first executable command/orchestration layer for Neo OrchestraX.

## Implemented

### Command parser
Parses:

```text
@package-selector
@package-selector for MoneyMap
@package-install android-kotlin-dev for MoneyMap
```

### Project resolver

Resolution order:

1. Explicit project
2. Single project
3. Ambiguous multiple projects
4. No project

### Command router

Recognizes:

- `@package-selector`
- `@package-install`
- `@context`
- `@task`
- `@handoff`
- `@resume`

V0.2 routes and resolves commands but does not yet execute the complete business behavior of these commands.

## Next

V0.3 can establish the canonical Pack model and real package discovery/installation.
