# Neo OrchestraX /skill

This is the Copilot Agent Skill projection of the provider-neutral Neo OrchestraX AI command `/skill`.

Usage: `/skill <skill-id> [for <project>]`

## Instructions
Inspect the requested OrchestraX skill and show its metadata, mapped agents, and content.

Treat this as an OrchestraX action, not a terminal command. Preserve explicit project targeting and do not substitute a different OrchestraX action. Use the available OrchestraX command/CLI bridge only when needed to execute the action.
