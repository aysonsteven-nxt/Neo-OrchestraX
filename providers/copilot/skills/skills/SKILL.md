# Neo OrchestraX /skills

This is the Copilot Agent Skill projection of the provider-neutral Neo OrchestraX AI command `/skills`.

Usage: `/skills [agent-id] [for <project>]`

## Instructions
Inspect the effective OrchestraX skills for the resolved project, optionally narrowed to an agent.

Treat this as an OrchestraX action, not a terminal command. Preserve explicit project targeting and do not substitute a different OrchestraX action. Use the available OrchestraX command/CLI bridge only when needed to execute the action.
